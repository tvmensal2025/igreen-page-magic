# Spike — Google Solar API (Fase 0)

Execute com variáveis de ambiente:

```bash
export GOOGLE_SOLAR_API_KEY=sua_chave
node experiments/solar-3d-ai/spike/run-spike.mjs
```

Sem chave, o módulo usa `SOLAR_USE_MOCK=true` (padrão em dev).
